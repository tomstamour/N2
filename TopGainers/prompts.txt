### Historical Gap Up Finder (HGUF)
I want you to design a script named the Historical_Gap_Up_Finder (HGUF) that will look into IBKR's historical database and find all the Gap Up Event for all stocks on the market in a define time period and output them in a dataframe named the HGUF-table. 
Arguments for the script:
--time-window <25-11-2025 10-12-2025> --minimum-gap-percentage <30> --max-open-price <float> --candles-size <10>

Fisrt lest define a Gap Up Even (GUE): 
-For a given stock, the price did gap over or equal to the --minimum-gap-percentage value in a time period starting from the previous day close price (RTH, daily candle close price) to the next day premarket end (09:29). Example: day-12 of the month, the price at 09:29 (pre-market) is 10$ and at day-11 of the month at RTH closing time (daily candles)the price was 5$, this represents a 50% GUE. When a GUE is detected the HGUF script will fetch the OHLC data for that stock with candle time as defined by the --candles-size option, the fetch will span from day-11 09:30 RTH (market open) up to day-12 16:00 RTH for that given stock and it will include the ETH (both pre-market and after-market) time period between the two days. 

The outputed HGUF-table will be a tab separated file and have the following header/ columns:
Symbol  | GUE  | Time  | O | H | L | C | Volume | GAP% | Push% | MAX  | Float | Institution%  |


The GUE column will host the "ID"  number of each Gap Up Event (GUE), one GUE id per Symbol per time period detected (day-11 to day-12 represent' a single time period) all the rows relative to a GUE will have the same number ID. The "GAP%" column will host the percentage GAP; The current % price relative to the "day-11" market close (RTH daily candle price), this value will only be displayed at rows of the time period of day-12 during pre-market (ETH), Add NA string in the rows were no value is displayed. The Push% column will host values in the rows at "day-12" RTH time only and the value will be the percentage of the current price relative to the opening price (first O (open) value of the first RTH candle of day-12), add NA string were no value are displayed. In the "MAX" column, enter the string "max" to the rows where the Push% value was the highest for a givent GUE, this string will appear only once per GUE. The Float column will host the float value of the stock on that day (repeat the value accros rows a the same GUE, same for Institution% and use yfinance data api fetch to get thoses values. 

Dont include OTC stock in the HGUF-table.
