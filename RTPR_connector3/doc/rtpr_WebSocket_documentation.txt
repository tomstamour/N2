Connect with ?apiKey=....
Server sends {"type":"connected"}.

You must send a subscribe frame — the firehose is not automatic:
Everything: {"action":"subscribe","tickers":[""]}
Or specific tickers: {"action":"subscribe","tickers":["AAPL","TSLA"]}

Server sends {"type":"subscribed","tickers":[""]}.

Server pushes {"type":"article","data":{ "id", "ticker", "tickers", "title", "article_body", "author", "created", ... }} for each release.


Every 30s the server sends {"type":"ping"} — you must reply {"type":"pong"} or you're dropped after ~90s (close code 4002).

you can subscribe to all tickers and you will get every article directly sent to you
